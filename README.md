# Idle Life (working name)

Fallout 4. Idle markers placed at run time, all over the world, each type where it belongs: people warm
their hands at every fire barrel, lean on bar counters, smoke on benches, dance by a radio at night.
Markers exist only around the player and are cleaned up as you leave.

Design and phases: [docs/DESIGN.md](docs/DESIGN.md). Status: phase 1 (catalog).
